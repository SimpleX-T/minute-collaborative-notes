# Minute Design System

## Direction

Minute is an engineering workbench, not a decorative sheet of paper. The editor occupies the visual center; navigation, presence, permissions, and meeting signals remain compact and peripheral. The interface should feel closer to a precise desktop tool than a marketing site.

## Visual Language

- Neutral mineral surfaces: white, graphite, fog, and cool gray.
- Cobalt communicates shared/live state; vermilion is reserved for risk or destructive actions.
- UI typography uses a pragmatic sans-serif; monospace is limited to code, shortcuts, and machine state.
- Borders establish structure; elevation is reserved for floating menus and the active editor surface.
- Radius range is 8–14px. Pills are reserved for status and compact permission controls.

## Composition

- Desktop: narrow document rail, fluid editor, contextual right panel.
- Tablet: right panel collapses first; document rail follows.
- Mobile: the editor owns the viewport and secondary controls move into menus.
- BlockNote slash commands and contextual formatting replace the permanent Markdown toolbar.

## Interaction

- Collaborative cursors use each participant's stable color and name.
- Sharing and lock state are always discoverable in the top bar.
- One authored motion moment accompanies room entry; ordinary state changes remain immediate.
- All hover behavior has an equivalent focus-visible state.

## Accessibility

Target WCAG 2.2 AA, minimum 44px touch targets on mobile, complete keyboard access, screen-reader names for icon controls, and no state conveyed by color alone.
