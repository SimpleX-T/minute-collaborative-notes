# Minute Design System

## Direction

Minute is a publication page that happens to be multiplayer. It borrows the reading confidence and restraint of independent publishing tools without copying their chrome. The document owns the experience; navigation, presence, permissions, and meeting signals stay quiet at its edges.

## Visual Language

- Light mode is white paper and charcoal ink; dark mode is a deliberately warm charcoal reading room, never inverted white.
- Warm signal orange marks authorship and consequential attention. Green is reserved for live and healthy state.
- Document typography uses Charter/Iowan/Georgia; controls use the platform sans; monospace is limited to code and data.
- Hairlines establish structure. Elevation is reserved for transient menus, dialogs, and floating notes.
- Corners stay compact at 3–6px. Circles belong to people and the theme control.

## Composition

- Desktop: narrow document rail, generous publication column, contextual right panel.
- Tablet: right panel collapses first; document rail follows.
- Mobile: the editor owns the viewport and secondary controls move into menus.
- BlockNote slash commands and contextual formatting replace the permanent Markdown toolbar.

## Interaction

- Collaborative cursors use each participant's stable color and name.
- Sharing and lock state are always discoverable in the top bar.
- The authored motion is ink settling onto the page: a brief blur-and-position resolve on room entry.
- Theme changes use View Transitions when available; ordinary feedback completes in 100–220ms.
- All hover behavior has an equivalent focus-visible state.

## Accessibility

Target WCAG 2.2 AA, minimum 44px touch targets on mobile, complete keyboard access, screen-reader names for icon controls, and no state conveyed by color alone.
